# Транспортные закупки — ЕИС, ТЭК-Торг и ЭТП ГПБ

Оконная программа (Windows) для мониторинга закупок автомобильных перевозок:
ЕИС (44-ФЗ и 223-ФЗ), ТЭК-Торг (КИМ, Роснефть, запросы (Т)КП) и ЭТП ГПБ
(etpgpb.ru: 223-ФЗ, коммерческие торги и закупки ГК «Газпром») с извлечением
марки/модели транспорта из названия и карточки закупки и выгрузкой в Excel.

Файл программы: `transport_tenders_parser.py` (версия 1.17.0).

## Быстрый запуск (Windows)

1. Установите Python 3.10 или новее с <https://www.python.org/downloads/windows/>.
   В установщике обязательно отметьте **Add python.exe to PATH**
   (компонент *tcl/tk and IDLE* включён по умолчанию — не снимайте его).
2. Скачайте эту папку целиком (`Code → Download ZIP` или `git clone`) и распакуйте.
3. Запустите **`run.bat`** двойным щелчком.

При первом запуске `run.bat` создаст в папке программы окружение `.venv`,
установит библиотеки из `requirements.txt` (нужен Интернет, 1–3 минуты)
и откроет окно программы. Следующие запуски — сразу открывают окно.

Если что-то пошло не так, окно консоли **не закроется** — текст ошибки останется
на экране, а подробности запишутся в `%LOCALAPPDATA%\TransportTenderParser\error.log`.

## Запуск вручную (без run.bat)

```bat
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python transport_tenders_parser.py
```

## Зависимости

Все библиотеки **обязательны** — `run.bat` ставит их автоматически из `requirements.txt`.

| Пакет | Назначение |
|---|---|
| `requests` | загрузка страниц ЕИС/ТЭК-Торг |
| `beautifulsoup4` | разбор HTML |
| `openpyxl` | выгрузка в Excel |
| `playwright` | обход антибот-защиты ТЭК-Торг через установленный браузер (требует Python 3.10+) |
| `tkinter` | оконный интерфейс — входит в стандартный Python для Windows |

Если какой-то библиотеки нет, программа при старте покажет окно с её названием
и командой установки, а не закроется молча.

### Как работает обход защиты ТЭК-Торг

Отдельно скачивать браузер для Playwright **не нужно**. Программа запускает
уже установленный браузер с отладочным портом и подключается к нему по CDP:

1. **Яндекс Браузер** — если установлен;
2. иначе **Microsoft Edge** (есть в любой Windows 10/11);
3. иначе **Google Chrome**.

Браузер открывается видимым окном со своим профилем в
`%LOCALAPPDATA%\TransportTenderParser\`. Если площадка попросит пройти проверку —
пройдите её один раз в этом окне; профиль сохраняется, и в следующий раз проверка
не потребуется.

### Как ускорен поиск и что исключается

Файлы документации закупки (PDF, DOCX, XLSX и другие вложения) **не скачиваются
и не сканируются**. Название техники и ТС берётся из названия и открытой HTML-карточки
закупки. Это устраняет последовательное чтение нескольких больших файлов для каждой
карточки. Уточнение данных в HTML-карточке можно включить отдельным флажком, но оно
также не обращается к вложениям.

В форме есть отдельное поле «Слова исключения». По умолчанию отбрасываются все виды
ремонта и восстановления техники (в том числе ремонт трала, тягача, полуприцепа,
гидравлики и капитальный ремонт двигателя), техническое обслуживание, диагностика,
мойка/автомойка/уборка, химчистка, детейлинг, покраска, шиномонтаж, страхование,
лизинг, аренда техники **без** экипажа, а также товарные закупки и запчасти:
поставка/приобретение/закупка автомобилей, спецтехники, тралов, тягачей,
бульдозеров, экскаваторов, погрузчиков и навесного оборудования, поставка запчастей,
комплектующих, шин, аккумуляторов, масел, смазочных материалов, гидроцилиндров,
ковшей, гусеничных лент и фильтров. Дополнительно остаются только записи, где
одновременно есть транспортный объект и признак перевозки, транспортировки,
доставки, перегона, аренды или оказания услуги.

В 1.17.0 в словарь поиска добавлена фраза «оказание услуг грузопассажирскими
автомобилями» — комбинированные перевозки людьми и грузом одним бортом (вахтовые
«бус-фургон», УАЗ, «вагончик»). В карточках таких закупок часто нет слов «перевозка»
или «автобус», поэтому слово добавлено в поисковый запрос, а не только в локальный
фильтр. Одновременно «грузопассажирский» распознаётся как транспортный признак и как
тип ТС, а аренда/прокат без экипажа отсекаются классификатором при любой формулировке
(раньше отсекались только точные фразы «аренда техники без экипажа» и
«аренда ТС без экипажа»).

В 1.15.0 расширен и сам список поисковых фраз — добавлены перевозки тралами и
седельными тягачами (в том числе низкорамными), негабаритными и тяжеловесными
грузами, транспортировка и перевозка землеройной и дорожно-строительной техники
(бульдозеры, экскаваторы, автокраны, самосвалы, манипуляторы, тракторы), работа
техники с экипажем и машино-час. Отсечение запчастей и расходников выполняется
до положительного фильтра, поэтому «поставка запчастей для экскаватора» не проходит
в выдачу по слову «экскаватор».

## Почему раньше «ничего не происходило»

Типичная причина — при двойном щелчке по `.py` Python падал на строке
`import requests` (библиотека не установлена), а консольное окно закрывалось
раньше, чем можно было прочитать ошибку. Теперь:

- отсутствие любой библиотеки показывается во всплывающем окне с командой для исправления;
- `run.bat` сам устанавливает всё необходимое и не закрывает консоль при ошибке;
- все необработанные ошибки (в том числе в фоновом потоке поиска) пишутся в `error.log`.

## Интерфейс

Внизу окна вместо стандартной полосы прогресса — синий грузовик, который едет
по дороге, пока идёт поиск.

## Частые проблемы

- **«Не найден Python 3.10 или новее»** — Python не установлен или не добавлен в PATH.
  Переустановите с python.org, отметив *Add python.exe to PATH*. Если стоит Python
  из Microsoft Store и он не находится — удалите его и поставьте версию с python.org.
- **«В установленном Python нет Tkinter»** — запустите установщик Python → *Modify* →
  отметьте *tcl/tk and IDLE*.
- **Не устанавливаются библиотеки** — нет доступа к pypi.org. Проверьте Интернет/прокси:
  `set HTTPS_PROXY=http://proxy.company.ru:3128` перед запуском `run.bat`.
- **ЕИС недоступна / ошибка сертификата** — включите в программе флажок
  «Игнорировать проверку сертификата TLS» и повторите поиск.
- **ТЭК-Торг просит проверку** — пройдите её один раз в открывшемся окне Яндекс Браузера;
  профиль сохраняется, и в следующий раз проверка не потребуется.
- **«ЭТП ГПБ недоступна»** — проверьте, открывается ли <https://etpgpb.ru/procedures/>
  в браузере на этом компьютере. Если сайт открывается, а поиск в программе нет —
  включите флажок «Игнорировать проверку сертификата TLS» и повторите поиск.
